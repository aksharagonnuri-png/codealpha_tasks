# Unemployment Analysis with Python

This project analyzes unemployment trends in India using Python.

## Objective

To analyze unemployment data in India and understand the impact of Covid-19 on unemployment rates through data visualization and exploratory data analysis.

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset

* Unemployment_Rate_upto_11_2020.csv

## Analysis Performed

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Unemployment Rate Distribution
* Regional Unemployment Analysis
* Monthly Trend Analysis
* Covid-19 Impact Analysis
* Correlation Analysis

## Conclusion

The analysis revealed significant variations in unemployment rates across different regions and highlighted the impact of the Covid-19 pandemic on employment trends in India.
